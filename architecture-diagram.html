AUTOMATION HARNESS

Suítes Playwright & POM

Desenvolvido em TypeScript com separação em camadas bem definidas:

  • E2E Specs: Testes funcionais da interface OpenCart via Page Object Model.
  • API & Contract: Validação de status HTTP 200/400/401 e schemas JWT.
  • Accessibility: Garantia de rotulagem e acessibilidade com leitores de tela.

MOCKING INFRASTRUCTURE

Servidor Mock Local

Servidor HTTP leve em Node.js (`mock-server.js` na porta 3001):

  • Isolamento de Rede: Simulação completa de cenários sem dependência externa.
  • Edge Cases: Validação de payloads vazios, tipos nulos e senhas extensas.
  • Alternância Dinâmica: Variável `USE_LOCAL_MOCK` chaveia entre Mock e API real.

AI EXPLORATION ENGINE

Agente Autônomo BetterWright

Exploração autônoma orientada a modelos de linguagem:

  • Agent Task Runner: `agent.mjs` executa varreduras no DOM usando LLM.
  • Integração com LLM: Modelo `codex/gpt-5.4` identifica campos, botões e formulários.
